# TekDocs 0.3.6 software inventory and licensing evidence

## Delivered

- Software-backed client assets now receive a scoped installation profile with planned, installed, suspended, and terminal uninstalled states; version, installation date, verification date, and optional client site are supported.
- Client licenses are addressable entities tied to retained supplier software provenance. Subscription, perpetual, and trial terms include status, bounded seats, term dates, renewal date/interval, auto-renew state, and a non-secret external reference.
- Explicit same-product installation coverage and retained person/installation seat allocations provide current counts without deleting historical assignments.
- License history is append-only and value-minimized. Central policy, MFA/CSRF mutation requirements, exact-workspace lookups, PostgreSQL guards, and forced RLS protect every route and relationship.
- The client Assets page now edits software installation state; the Licenses page lists entitlements, renewal state, covered deployments, active seats, and history.

## Boundary

TekDocs does not store software license keys, activation secrets, credentials, or provider tokens. Renewal notification scheduling, costs/contracts, attachments, bulk operations, CSV transfer, MSP-owned asset topology, and connector reconciliation remain later work.
