# TekDocs 0.2.6 document transfer evidence

Date: 2026-08-09

Status: **complete and locally certified.** No push, tag, deployment, Wiki publication, or other external change was performed.

## Delivered scope

- Added portable document categories and an explicit reusable-template designation, with workspace-safe search and filtering.
- Added template instantiation into an independent destination-owned document. Resolved Markdown is copied, managed attachments receive new identities and opaque storage keys, and attachment references are rewritten atomically.
- Added private managed attachments with stable UUIDs, exact document ownership, bounded and signature-validated uploads, server-derived metadata, soft removal, and authorized forced downloads. There is no public media route or inline active-content rendering.
- Added bounded UTF-8 Markdown import through the normal immutable document service and deterministic resolved-Markdown export with safe filenames.
- Added restrained category, template, import, export, upload, insert-reference, download, and removal controls to the existing Documentation interface.

## Known boundaries

- Local persistent storage is the first attachment provider. S3-compatible storage, malware scanning, quarantine, and the broader hostile-file corpus are assigned to `TD-RISK-021` and rescheduled to `0.3.9`; current files remain private, forced-download only, narrowly allowlisted, and never archive-extracted.
- Milkdown preserves canonical `tekdocs://attachment/{uuid}` Markdown, while its visual link widget does not present that custom scheme as a navigable browser link. The authorized attachment list and server preview provide the working download/card surfaces; raw Markdown remains available for exact editing.
- Template instantiation is an independent copy, not inheritance. Later changes to the source template or its attachments intentionally do not update documents already created from it.
