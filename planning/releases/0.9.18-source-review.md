## Spec

Fresh Spec/security review identified one P2 proof gap: DjangoJSONEncoder drops
sub-millisecond timestamp precision from the client retention fingerprint. A real
Docker cohort reproduced an identical public recovery fingerprint after a legal
one-microsecond change to an MSP notification read time. The new encoder retains
full ISO datetime precision and the regression exercises the public fingerprint,
restoring its synthetic read status in finally. It does not alter publication
records, signatures, application serialization or production data. This follows
the existing standalone monitored-source proof pattern and remains baseline-
compatible. All 25 client cohort cases passed on the installed 0.9.18 backend after the
correction; narrow Spec and Standards re-reviews report zero remaining findings.
No other scope mismatch was found: normal migration 0212, preserved client
identities/artifacts, independent approval, same-audience corrections, withdrawal,
authority rollback/recovery and complete automatic release delivery remain aligned.

## Delivery boundary

Required source review and risk disposition precede the authorized release push.
Exact-source hosted gates then validate and publish the same tested four images,
verify provenance/SBOM attestations and deliver application plus receipt tags.
The source branch stays on the application commit. Production deployment remains
separate; no new independent-human or final 1.0 acceptance claim is made.
