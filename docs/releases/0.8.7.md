# TekDocs 0.8.7 public-beta security hardening

## Delivered

- Production file-only enforcement for required Django, database, encryption, publication, configured SMTP, and configured OIDC secrets.
- Read-only application containers, tmpfs write boundaries, dropped capabilities, `no-new-privileges`, process ceilings, bounded Gunicorn recycling/timeouts, and graceful shutdown.
- Bounded, allowlisted JSON application/request logs with credential redaction and value-free exception signaling.
- Python and npm production license policy checks alongside existing vulnerability, secret, source, and image scans.
- Pinned ZAP passive DAST in the isolated production rehearsal, with no retained raw security artifact.
- Upload-memory ceilings and retained authentication/CSRF/rate-limit, SSRF, IDOR, hostile-file, Markdown, webhook, and isolation abuse gates.

## Verification

- `make check`
- `make test-auth-abuse`
- `make test-secret-files`

The DAST baseline reports no configured FAIL finding. Cacheable static content, the documented Markdown/editor inline-style allowance, modern-application detection, and missing COEP remain reviewed non-blocking observations rather than suppressed evidence.

## Remaining boundary

This is local production-target evidence. It is not an external penetration test or proof of a signed published image. External review remains `0.8.9`; signed images, SBOM publication, attestations, and provenance remain `0.9.4`.
