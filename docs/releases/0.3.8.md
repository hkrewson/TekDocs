# TekDocs 0.3.8 MSP operational parity evidence

## Delivered contract

- The MSP owns operational records through tenant scope with `organization IS NULL`; it is not represented as a client and its pages never aggregate client-owned rows.
- Dedicated MSP API routes and browser surfaces now cover retained-provenance assets, hardware lifecycle, software installations and licenses, seat allocation, contracts, protected cost lines, and derived vendors.
- Client and MSP routes reuse the same policy-aware services while resolving different exact data scopes. Direct identifiers cannot cross from client to MSP or MSP to client.
- Supplier catalog access in MSP mode is a read-only RLS projection limited to supplier catalog records and their explicitly associated client-visible STATIC publications. It does not expose client operational records or unrelated supplier documents.
- Nullable owner edges use PostgreSQL `IS NOT DISTINCT FROM` guards. Hardware serial and asset-tag uniqueness treats the MSP null owner as a real partition.
