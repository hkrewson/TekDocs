# TekDocs 0.0.7 password recovery evidence

Date: 2026-08-07

Status: verified locally; hosted GitHub workflows remain pending publication.

## Delivered scope

- Sign-in now exposes a visible password-recovery workflow with the same confirmation state for every submitted account address.
- Password reset uses allauth headless endpoints and Django’s maintained, password-bound token generator with a one-hour default expiry.
- Reset keys are placed in email URL fragments, removed from browser history before rendering account entry, retained only in component memory, and never placed in request URLs.
- Known-account reset and password-change messages use the central multipart transactional email service.
- Completion applies the configured password validators, does not auto-login, makes the key unusable, and invalidates all existing sessions through Django’s password-derived session hash.
- Invalid, malformed, expired, and already-used links share one browser unavailable state.

- `make check`: passed Ruff, mypy, migration drift, OpenAPI drift, frontend lint/type checks, 32 frontend unit/component tests, and the production build.
- `make test`: passed 66 backend tests with three PostgreSQL-only concurrency skips and 90.41% aggregate coverage, plus all 32 frontend tests with 85.78% statement coverage.

- `make test-e2e`: passed 11 Chromium workflows, including reset-request accessibility, fragment removal, successful completion, invalid-link handling, invitation activation, authentication, navigation, and canonical Markdown editing.

- OpenAPI generation and drift validation passed at version `0.0.7`; the maintained allauth headless interface remains outside the TekDocs `/api/v1` schema by design.

## Boundaries carried forward

- Explicit session inventory/revocation, authentication audit expansion, login throttles, and recovery-rate policy remain `0.0.8`.
- TOTP, recovery codes, recent reauthentication, and privileged-role enforcement remain `0.0.9`.
- Password recovery intentionally returns users to sign-in instead of creating an authenticated session.
