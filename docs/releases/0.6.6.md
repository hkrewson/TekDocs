# TekDocs 0.6.6 provider operations

Date: 2026-08-12

Status: **local slice complete with an explicit remaining owner.**

Adds a 30-day provider-event ledger limited to fixed event codes and non-negative numeric metrics. Provider tokens, request/response bodies, remote labels, cursor values, arbitrary exception text, and provider JSON are not accepted. This mitigates the integration-specific portion of `TD-RISK-015`; replacing the process-wide JSON-shaped formatter remains assigned to `0.8.7`.

Evidence is consolidated in `docs/releases/0.6.8.md`.
