# TekDocs 0.9.5: Managed Git authoring

Date: 2026-10-05. Application version is `0.9.5` after issue #104.

## Completed slice

- Staff with document-edit permission can use a separate Repository content
  surface to create Markdown documents and fragments, edit body and portable
  metadata, and move files in the current workspace repository.
- Targeted source patches retain untouched frontmatter and comments. A move
  retains the previous path as a validated alias. Stable UUID links and
  inclusions do not need path rewrites.
- Exact base commit/blob checks and the repository compare-and-swap prevent
  concurrent changes to the same file from silently overwriting one another.
  The response includes base/current/proposed source for explicit review and
  rebase; unrelated head changes can merge.
- The full candidate graph is checked before Git acceptance. Accepted/indexed
  markers expose and retry interrupted projection work without treating the
  newest filesystem commit as authority.

## Validation evidence

- `make test-content-authoring` passed against PostgreSQL in Docker, covering
  targeted edits, aliases, invalid composition, same-file conflicts,
  unrelated-head merges, API permission and workspace denial, retry,
  content-index behavior, forced RLS and API contracts.
- `make check` passed: 691 frontend tests, production frontend build,
  language/responsive contracts, lint/type checks, version alignment,
  migration drift and OpenAPI alignment. The focused Repository content tests
  also passed after the final focus-handling adjustment.
- OpenAPI and generated TypeScript contracts were regenerated from the new
  endpoints. No database schema migration is needed because existing accepted
  and indexed commit markers provide the retry signal.

## Deliberate limits

The legacy database editor remains distinct. Its documents are not silently
migrated to Git; migration belongs to `0.9.6`. Publication, portal/file parity
and repository-inclusive recovery belong to `0.9.7`. Optional GitHub remotes,
deployment and hosted validation are not claimed by this local checkpoint.
