# 0.9.7 progress: exact Git publication-source proof

Date: 2026-10-07. Application version remains `0.9.6`. This is the first
internal foundation for [issue #106](https://github.com/hkrewson/TekDocs/issues/106),
not a `0.9.7` release or an authority handoff.

## Bounded result

`freeze_git_document_dependencies` produces a deterministic, value-free proof
of one repository document's accepted commit, root Markdown blob, and ordered
audience-visible live or pinned fragment blobs. It records path, commit, blob
ID, exact-byte SHA-256, and composition identity. It re-reads Git content, recomputes the bounded
composition, checks the current index and fails closed on index lag, projection
drift or missing pinned source objects. There is no new route, database schema,
or stored publication format in this step.

## Validation and remaining work

The synthetic PostgreSQL/Docker composition suite covers nested pins, live
sources, audience filtering, exact SHA-1 Git blob identity, deterministic
repeat, projection tampering, accepted-head lag and missing pinned objects.
The broader `make test-content-composition` gate and repository-wide `make
check` gate passed locally against this step, including backend static checks.

The existing STATIC publisher remains database-authored. Transactional
accepted-head pinning and signed-manifest integration, attachments, editable
and sanitized exports, templates/monitored sources, client listing/portal
parity, encrypted repository-inclusive backup/restore, and recovery fault
rehearsals remain open in `0.9.7`. No production cutover, deployment, or hosted
CI result is claimed here.
