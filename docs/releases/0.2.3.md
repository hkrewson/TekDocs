# TekDocs 0.2.3 immutable revision evidence

Date: 2026-08-09

Status: **verified locally.** No push, tag, deployment, Wiki publication, or other external change was performed.

## Delivered scope

- Moved canonical block Markdown into append-only revisions with parent chains, sequence numbers, SHA-256 checksums, author/timestamp attribution, and an atomic current pointer.
- Added exact-base optimistic concurrency. Stale writes return a structured conflict and unified diff without changing stored content or discarding the browser draft.
- Added MSP and organization revision-history APIs and a restrained, accessible history/diff interface.
- Added database guards, forced RLS, route inventory coverage, negative isolation, raw-mutation, and migration-preservation tests.

## Verification

- `make check` passed backend formatting, Ruff, mypy, migration drift, OpenAPI drift, frontend lint/type checks, 129 frontend tests, and the production frontend build.
- `make test-compose` passed 526 PostgreSQL-backed backend tests at 91.58% coverage, plus the Compose runtime, SMTP, and provenance checks.
- `make test-e2e-all` passed 93 browser tests across Chromium, Firefox, and WebKit.
- `make test-e2e-live` passed the real Chromium-to-Django-to-PostgreSQL journey and verified the exact two-revision database chain and current-revision pointer.
- `make security` reported no known Python or npm dependency vulnerabilities, no Bandit findings, no detected secrets, and no High or Critical findings in the scanned runtime images.

- `make upgrade-rehearsal` preserved the baseline fixture and passed the `0.1.3` to `0.2.3` migration path.
- `make production-image-rehearsal` passed with the production-target backend, worker, scheduler, migration, and frontend images.

## Known boundaries

- Placements still resolve the block's current revision; explicit live/pinned modes and transclusion begin in `0.2.4`.
- History is intentionally capped at 200 newest revisions until pagination and large-history performance work in `0.2.9`.
- Line diffs are review aids, not a three-way merge editor. A stale browser draft is retained for manual reconciliation.
- Checksums detect and identify content but are not signatures. Signed immutable publication begins in `0.2.7`.
