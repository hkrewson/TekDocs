# TekDocs 0.8.4 localization readiness

Date: 2026-08-13

Status: **local slice complete.** Only `en-US` ships; this is not a claim of translated-language coverage, public release, deployment, tag, or push.

## Delivered boundary

- A typed browser localization seam negotiates only shipped catalogs, publishes document language/direction, and provides stable message substitution plus centralized date/time/hour/integer formatting.
- Shared pagination and shell bypass navigation use stable catalog IDs; notification, security-session, and recycle-bin time presentation use the formatter seam.
- Offset-free timestamps fail closed, date-only values remain calendar-stable, explicit IANA zones handle DST, and browser-zone fallback is defined.
- Server and Compose defaults are UTC. Production validates `TZ` as one bounded IANA zone, while workflow-specific notification zones remain explicit domain state.
- The contributor contract separates localized presentation from API identifiers, canonical Markdown, signatures, audits, and integration data, and defines the evidence required before adding a locale.

## Evidence

- `make test-localization`
- `make check`
- `make test-e2e`

Existing feature copy continues to migrate as its surface is hardened. Adding another locale requires a complete reviewed catalog and browser/mail/PDF/accessibility evidence rather than machine-translating isolated strings.
