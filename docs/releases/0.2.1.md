# TekDocs 0.2.1 Markdown contract evidence

Date: 2026-08-09

Status: **verified locally.** Hosted GitHub Wiki/workflow evidence remains externally blocked pending explicit repository-publication authorization.

## Delivered scope

- Adopted the final pre-persistence Markdown dialect in ADR 0019, including task lists, tables, footnotes, strikethrough, `==semantic highlight==`, and NOTE/TIP/IMPORTANT/WARNING/CAUTION callouts.
- Added a restrained persistent structural toolbar for paragraph/headings, lists, task lists, quote, code, table, divider, callout, undo, and redo; the contextual selection toolbar adds semantic highlight and remove-formatting actions.
- Retained Markdown as the only canonical value while adding explicit Editor, Markdown, Preview, and Formatting help modes.
- Added an authenticated, CSRF-protected, permission-cataloged `/api/v1/markdown/render` boundary with a one-million-character request ceiling, raw HTML disabled, and a strict server allowlist.
- Added an explicit DOMPurify allowlist as browser defense in depth around the single preview HTML sink.
- Adopted the supplied UniFi guide as a permanent realistic round-trip fixture and combined it with every supported technical extension.
- Added malicious rendering, API authorization/size, sanitizer, editor round-trip, component, browser, and accessibility coverage plus `make test-markdown`.
- Established the actual public GitHub Wiki as the future end-user/operator documentation home and the in-app help surface as the immediate internally hosted reference. Repository docs remain engineering and release artifacts.

- The GitHub Wiki has not been created or published because no external publication was authorized.
