# TekDocs 0.7.2 scoped compliance assignments

Date: 2026-08-12

Status: **local slice complete.** No push, tag, deployment, or certification claim is implied.

This slice adds one exact-Workspace assignment per stable compliance control, pinned to the control revision reviewed. Applicability, implementation status, an optional authorized TekDocs user owner, review due date, and append-only review decisions are available through MSP/client APIs and the Compliance surface. Owner choices are active users who independently retain access to that exact workspace; assignment does not grant access. PostgreSQL repeats Workspace, control, revision, owner, reviewer, retention, and forced-RLS constraints.

The blocking slice gate covers service and API behavior, strict schemas, owner denial, sibling-client IDOR, immutable review history, direct PostgreSQL guard failures, forced RLS, migration drift, OpenAPI/generated-client drift, and frontend owner/review behavior. Evidence and risks remain outside this slice.
