## Reproduced evidence-retention defect

The previous passing local rehearsal left zero files in
`artifacts/playwright-performance`. The hosted artifact list likewise contained
no performance artifact. The script mounted `/app/test-results` but Playwright
wrote to its container-local default, and the safe summary destination was unset.
The correction writes a value-safe summary and diagnostic files directly into
the mount, on pass and failure. Raw browser artifacts remain container-local.

Ranked hypotheses for the original timing failure:
1. Editor downloads are unfinished at the readiness deadline.
2. Downloads complete but editor initialization fails or stalls.
3. Runner contention delays browser work after downloads finish.

Counters and phase timings distinguish these hypotheses without retaining
payloads or weakening the existing test. A separate manual workflow runs five
fixed repetitions with one worker and zero retries; any failure fails the run.
It does not create or replace complete release evidence.

## Confirmed static-delivery gap and correction

The unchanged five-repetition local baseline passed 20 cases (mobile legacy editor
8,159–8,219 ms). The original hosted access log and a Docker GET with gzip accepted
both showed 1,142,067 bytes of uncompressed editor JavaScript. Nginx had no static
compression configuration, despite build budgets measuring compressed bytes.

A disposable configuration-only experiment enabled gzip on public static assets;
all 20 cases passed and mobile editor readiness fell to approximately 3.1 seconds.
The committed routing regression was first run against the old image and failed
twice, once per editor JS/CSS bundle, because Content-Encoding was absent. With
the correction, all six routing tests pass. They verify decoded-byte identity,
identity/gzip negotiation, Via proxy support, unchanged cache/security headers,
uncompressed HTML and existing 404 behavior. Compression is scoped to build assets;
no API, schema, authorization, or editor implementation change is made.

This is a reproduced transport defect and measured performance improvement. It
is not proof of the original hosted timeout's exact cause; that diagnosis remains
open until the full-context hosted diagnostic run supplies evidence.

to reduce constrained-connection loading time, retaining the existing performance
