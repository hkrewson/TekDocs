# TekDocs 0.8.3 accessibility hardening

Date: 2026-08-13

Status: **local slice complete.** This is engineering evidence, not independent WCAG certification, a public release, deployment, tag, or push.

## Delivered boundary

- A documented WCAG 2.2 AA contract covers authentication, shell navigation, editing/publication, portal, inventory, monitoring, and administration.
- The authenticated shell now provides visible skip navigation while route transitions focus the new main region without stealing initial focus.
- The profile menu closes with Escape and returns focus; editor tabs expose a complete ARIA relationship and Left/Right/Home/End keyboard behavior.
- Quiet text contrast was raised, the workspace search exposes a visible composite focus ring, reduced-motion preferences suppress nonessential transitions, and forced-colors mode retains selected navigation/editor state.
- Playwright asserts bypass navigation, route focus, menu focus return, editor tab behavior, and WCAG 2.2-tagged axe scans on critical surfaces.
- The aggregate test target now runs the PostgreSQL-dependent migration corpus against PostgreSQL instead of attempting PostgreSQL trigger migrations on SQLite.

Automated tools do not establish conformance by themselves. The manual audit contract remains recurring, the full browser/device matrix is `0.8.6`, external review is `0.8.9`, and final release-candidate remediation is `0.9.5`.
