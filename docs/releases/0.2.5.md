- Added permission-filtered backlinks and bounded reuse-impact projections derived from the canonical placement and client-listing graph.

## Known boundaries

- Backlinks are derived from active document placements and listing references; historical revision text is not independently indexed for mention backlinks.
- Impact output is capped at 500 authorized audience rows. The response states when additional authorized rows were truncated.
- Entity reference cards are display projections, not embedded entity snapshots. STATIC publication will resolve exact projections in `0.2.7`.
