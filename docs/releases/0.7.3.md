# TekDocs 0.7.3 reusable compliance evidence

Date: 2026-08-12

Status: **local slice complete.** No push, tag, deployment, or certification claim is implied.

This slice adds reusable Entity-backed compliance evidence to one exact MSP or organization Workspace. Evidence supports bounded note, URL, or Entity sources, optional collection windows, append-only review decisions, and retained assignment links pinned to exact control revisions. A single evidence object may support multiple assignments without copying content, and may be linked again when control wording advances without rewriting older provenance.

The blocking slice gate covers service and API behavior, strict schemas, sibling-client IDOR, immutable link/review history, direct PostgreSQL guard failures, forced RLS, migration drift, OpenAPI/generated-client drift, and frontend create/review/reuse behavior. Risk treatment and signed evidence bundles remain outside this slice.
