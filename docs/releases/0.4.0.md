## Known boundaries

- “Certified” means the documented local repository gates passed for the implemented scope. It is not independent security certification, a penetration test, a provider guarantee, or a legal/compliance designation.
- Customer credential values remain outside TekDocs. A compromised host can expose reference metadata and Private Links, but 1Password still requires its own item/vault authorization and unlock.
- The built-in attachment scanner remains structural/content defense in depth rather than a maintained malware-signature engine.
- MSP routes are operational views of the explicit MSP Workspace, not cross-client reports. Hosted multi-MSP isolation and the final 1.0 capacity target are not claimed.
