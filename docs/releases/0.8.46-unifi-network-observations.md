Date: 2026-09-28

Status: **local pre-1.0 slice.** No push, tag, production deployment or external

## Delivered boundary

- UniFi Network can be configured as a read-only integration with an encrypted API
  key and an editable local console/API URL.
- Synchronization reads only sites, configured networks, adopted devices, connected
  clients and Wi-Fi broadcasts through the official integration API.
- CIDR, DHCP, DNS, adopted infrastructure and Wi-Fi facts are reduced to the existing
  five-view Networks contract.
- Fresh workspaces deterministically create or reuse supported CIDRs, catalog models,
  hardware Assets, network Devices, unassigned client IP rows and Wireless records.
- A transient connected client never creates an Asset or NetBox device.

## Security and ownership decisions

API-key plaintext exists only at decryption and the approved pinned egress boundary.
Redirects, cross-origin cursors, non-JSON responses and oversized pages fail closed.
Provider payloads are fingerprinted, while only flat allowlisted operational facts
are retained for review.

Synchronization performs no provider writes. NetBox publication remains a separate
reviewed workflow requiring a separate write credential, a current proposal and an
audited result. NetBox retains authority for durable inventory facts; UniFi retains
authority for live connectivity observations.
