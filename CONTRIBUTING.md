# Contributing

Start with `AGENTS.md`, `README.md`, the current issue or milestone, and the public GitHub Wiki when it is available. Keep changes aligned to one roadmap slice and include tests for behavior and security boundaries.

By contributing, you certify the Developer Certificate of Origin 1.1 using a `Signed-off-by` trailer in each commit (`git commit -s`). Do not submit customer data, credentials, proprietary code, or dependencies with unclear redistribution rights.
