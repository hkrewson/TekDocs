# TekDocs 0.4.2 network addressing evidence

Date: 2026-08-11

Status: **implementation and applicable local evidence complete.** No push, tag, image publication, deployment, or other external change was performed.

## Delivered scope

- Stable exact-Workspace VRF, VLAN, and subnet Entities with non-aggregating MSP and exact-client routes.
- Canonical IPv4/IPv6 prefix storage, derived address family, bounded Workspace-unique VLAN IDs, optional VRF/VLAN associations, and restrained searchable management surfaces.
- An explicit overlap contract: the default routing table and each VRF are independent namespaces; intersections inside one namespace fail, while identical prefixes in different VRFs remain valid.
- Central network permissions, route inventory, forced PostgreSQL RLS, advisory-lock serialization, direct-write ownership/canonical/overlap guards, value-safe audit events, and property/concurrency/IDOR tests.

## Known boundaries

- Route distinguishers are descriptive metadata, not validated BGP configuration. VLANs do not imply routing isolation.
- Individual addresses, interfaces, MAC assignments, circuits, wireless records, diagrams, NetBox reconciliation, bulk transfer, recycle-bin behavior, and final scale certification remain later `0.4.x` slices.
- “Complete” records local repository evidence for this bounded slice. It is not third-party certification, a penetration test, or a hosted multi-MSP claim.
