## Delivered boundary

- The isolated production-asset browser rehearsal now supports complete desktop Chromium, Firefox, and WebKit projects.
- Targeted Pixel-class Chromium and iPhone-class WebKit projects exercise small-screen reflow, navigation, keyboard/touch operation, page overflow, and WCAG 2.2 automated rules.
