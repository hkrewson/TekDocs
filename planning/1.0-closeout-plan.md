# Immediate Git-backed document and 1.0 closeout

Status: maintainer-authorized work sequence, November 2, 2026.

The objective is to finish Git-backed documents, establish a finite supported
1.0 contract, and close release acceptance. Full completion of the currently
scoped migration work remains an acceptable outcome. No remaining valid legacy
shape is silently deferred merely to reach a version number. This plan orders
the work; it does not claim that the support matrix or release is accepted.

## 1. Freeze the 1.0 document contract

Reconcile the [remaining migration audit](migrations/remaining-migration-audit.md)
with legacy behavior, reproducible fixtures and available document inventory.
The six recorded shapes are the finite starting queue:

1. Same-Workspace pins predating represented Git history.
2. Body-only reuse of a source Block that owns children.
3. Consumer-owned children below reused placements.
4. Incoming and non-neutral/metadata-bearing record relationships.
5. Removed, archived owned blocks in migration inventory.
6. Parameterized foreign reusable bodies using consumer bindings.

For each, record current behavior, preservation requirements, supported migration
behavior, positive/negative tests and a required/deferred/prerequisite decision.
Default to completing valid existing behavior where that is the sound solution.
A proposed deferral needs an explicit rationale, a usable retained legacy path,
rollback/recovery evidence and maintainer acceptance. Absence from a sample alone
does not establish that a valid supported legacy shape can be discarded.

Keep corrupt/missing/unscanned bytes, invalid signatures/scopes, revoked sharing,
cycles and ambiguous business mappings as explicit fail-closed prerequisites.
New product capabilities require a separate scope decision rather than entering
this migration queue implicitly. No production inventory or mutation is implied
by this planning record.

Exit: one reviewed support matrix accounts for all six shapes and all known
blockers, with no unclassified valid shape or implicit loss of existing behavior.
