# TekDocs 0.6.2 scoped API tokens

Date: 2026-08-12

Status: **local slice complete.** No push, tag, deployment, or hosted workflow is implied.

## Delivered boundary

- Personal and dedicated service API tokens carry exact MSP/organization Workspace and explicit permission scopes, always intersected with current central policy.
- Raw bearer material is returned only at issue or rotation and stored only as a maintained password hash. Expiry is mandatory; rotation/revocation is immediate; last-use writes are throttled.
- Issue/rotation is session-, CSRF-, TOTP-, and recent-reauthentication protected. Service identities cannot interactively authenticate or become privileged staff.
- Bearer identity is established before forced-RLS binding. PostgreSQL guards service classification, token authority/lifecycle, tenant edges, and immutable permission rows.
- Settings now lists safe token metadata and provides organization search, permission selection, copy-once issue/rotation, and explicit revocation.
- OpenAPI declares bearer authentication and token management; the checked TypeScript client is regenerated from it.
