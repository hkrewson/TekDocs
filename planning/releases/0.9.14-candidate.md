list after another document in the Workspace becomes Git-authoritative. Empty
search now combines legacy and repository results before existing sorting,
facets and pagination, matching text-search visibility. The merged regression
covers combined counts, content authority, second-page results, exclusions,
empty-result search and template filtering. Existing scoped query helpers and
repository-ID exclusions remain in use; the fix adds no permission grant or
content mutation. No new release-blocking issue was identified in this bounded
source delta review. See [reproduction and runtime evidence](../migrations/mixed-authority-document-list.md).

No data repair, rollback or additional document promotion is required for this
listing correction. The separately blocked publication-bearing guide remains
outside migration eligibility. The local Wiki Documentation draft already
explains mixed-authority list behavior; no new public procedure is needed.
Wiki publication remains separately authorized, and existing Wiki edits are
preserved.
