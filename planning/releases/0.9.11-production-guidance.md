# 0.9.11 production update

Status: publication verified October 22, 2026; production deployment pending.

## Update commands

From the existing production TekDocs checkout, fetch the reviewed tooling and
receipt, then select the release explicitly:

```bash
git fetch origin codex/assigned-organization-candidate
git switch --detach FETCH_HEAD
scripts/update-production.sh --release v0.9.11
```

The updater retains the saved backup paths in `.tekdocs-update.env`. If those
paths were never saved, supply the existing `--backup-root` and `--recovery-key`
paths. Do not bypass backup to resolve a receipt or branch error.

The detached tooling checkout is intentional. The explicit `--release` selects
application commit `bec54d0c294820599db6028116a83d11d5c28f82` and its four reviewed
image digests. Without `--release`, the updater follows a tracking branch and
rejects a checkout without an upstream. The frozen application tag predates
its publication receipt; use the newer tooling checkout above.

was not inspected; the separate upstream error is explained by the updater's
non-release branch check, not evidence of a failed image publication.

The complete security/diagram publication record and pinned status manifest
refresh remain separate closeout work; the existing manifest still identifies
v0.9.9. No production deployment or post-update smoke is claimed here.

## Mailpit security rebuild

Mailpit remains the default local mail catcher; it does not deliver mail to
external recipients. Production installations needing real delivery must
configure SMTP and its secret-file overlay. Do not remove Mailpit while
`EMAIL_HOST=mailpit` or while Compose startup dependencies still require it.

From 0.9.11 the release supplies a fourth immutable image, `tekdocs-mailpit`,
rebuilt from pinned upstream source with Go 1.27.3. The updater requires the
Mailpit digest in new release receipts, validates its revision and verifies the
running container. Existing mail data and ports are retained. Older receipts
remain supported. Use the reviewed updater/receipt revision above; no manual Compose edit is necessary.

The [maintenance and upstream return procedure](../../mailpit/README.md) explains
how to replace the temporary rebuild with a scanned upstream stable image while
preserving the delivery contract. This section is the source for the next Wiki
production-image/upgrade guidance update; publication is a separate action.
