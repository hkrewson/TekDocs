# TekDocs 0.9.6: Legacy document copy and coexistence

Date: 2026-10-06. Application version: `0.9.6`. This is a local development
checkpoint for issue #105, not a Git-authority cutover or production deployment.

## Completed slice

- An exact-workspace, read-only inventory classifies every legacy document and
  reports first-wave candidates, repository readiness and explicit deferrals.
- Preview exports stable-ID document and fragment Markdown, portable topic,
  taxonomy, property, field-key and supported entity-reference metadata,
  attachment bindings, and exact same-workspace live or historical pinned leaf
  references. It validates the combined graph and legacy composed-Markdown
  parity without writing Git or exposing document bodies in its JSON.
- A preview-bound, audited compare-and-swap import copies one eligible
  document, indexes and verifies the accepted commit, and supports idempotent
  retry after interrupted indexing. An unchanged copy can be rolled back by a
  new audited commit only when no outside content depends on it.
- Authorized migration status compares copied bytes and projection with the
  current legacy document and performs a reader-scoped shadow read of title,
  Markdown, rendered HTML and supported outgoing relationships. It exposes
  handoff blockers; it never promotes Git to legacy read or write authority.
- The [operator procedure](../DOCUMENT_MIGRATION.md) states prerequisites,
  commands, failure states, guarded rollback and intentional deferrals.

## Validation evidence

- `make test-document-migration-inventory` passes the migration, command,
  route, rollback, and forced-RLS tests against PostgreSQL in Docker.
- `make document-migration-upgrade-rehearsal` proves stable IDs and retained
  revisions from `0.8.46` through upgrade, then compares deterministic
  first-wave copy, retry, explicit template deferral and rollback with a
  fresh installation. The rehearsal uses isolated synthetic stacks.
- `make check` passed: 691 frontend tests, lint, typecheck, build, API schema,
  backend lint/typecheck and migration-drift checks.
- `make test-content-authoring` passed the focused authoring, composition,
  read, RLS and API-contract suite.
- `make production-image-rehearsal` passed the production-shaped container,
  secrets, renderer, repository custody and persistence checks.

The aggregate `make document-migration-release-gate` also passed on
2026-10-06. The local `0.9.6` acceptance gates are therefore green. The
[public migration guide](https://github.com/hkrewson/TekDocs/wiki/Imports-and-migration)
and Wiki roadmap were published in Wiki commit `75ceee0f9705fb4189491f8593489737218fc061`.
This closes the bounded local development slice, not a hosted release or
production authority transition.

## Deliberate limits

Templates and enrollments, publications, primary-file version chains,
cross-workspace reuse, content-expanding keys and unsupported relationship
forms remain visible deferrals, not silent conversions. The legacy editor,
reads, revisions, review workflow and publications remain authoritative.
Repository-inclusive recovery, publication/file/portal parity and any
authority transition belong to later checkpoints. This local release record
does not claim a hosted CI result, deployment, independent
human security review, or the final 1.0 acceptance matrix.
