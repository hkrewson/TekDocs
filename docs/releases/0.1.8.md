# TekDocs 0.1.8 typed entity links evidence

Date: 2026-08-08

Status: verified locally; hosted GitHub workflows remain pending publication and a pull request.

## Delivered scope

- Entity relationships use a bounded catalog with explicit forward and inverse labels, symmetric behavior where appropriate, and classification-aware target eligibility.
- Stable Entity endpoints provide outgoing relationships and incoming backlinks without copying names or ownership into mutable link metadata.
- Route-derived APIs list, create, and archive links while refusing self-links, duplicates, arbitrary types, caller-supplied ownership, metadata, foreign tenants, and inaccessible sibling workspaces.
- PostgreSQL migration-owned guards enforce same-tenant endpoints, canonical symmetric ordering, empty metadata, immutable identity, and append-only archival state even when application services are bypassed.
- Workspace-aware entity search is bounded before filtering and pagination. Results expose only stable identity, display name, Entity type, owning-workspace label, and eligible relationship types.
- Organization overviews show relationships and reverse backlinks, search eligible organization targets, add a typed link, navigate to authorized targets, and archive through a two-step confirmation.
- Relationship mutations produce value-free audit events and remain installation-owner-plus-MFA operations until the central policy and scoped RBAC milestones.

## Known boundaries

- The first relationship-management interface is on organization overviews. The API and Entity model support later People, Site, asset, network, document, and other domain surfaces.
- The catalog is intentionally code- and migration-maintained in this slice. Custom relationship types, free-form link notes, arbitrary metadata, validity periods, and bulk relationship import remain later work.
- Archived links remain in PostgreSQL and audit history but are excluded from active relationship and backlink listings.
- Search eligibility is not mutation authority. Every link creation is revalidated under lock at write time.
- Local Compose intentionally permits HTTP and therefore reports Django's HTTPS-redirect deployment warning. The production-image rehearsal enforces the production settings contract.
- PostgreSQL RLS, database-enforced audit immutability, secret-file enforcement, reproducible supply-chain inputs, backups, hosted automation evidence, and the editor bundle warning remain tracked in the engineering risk register.
