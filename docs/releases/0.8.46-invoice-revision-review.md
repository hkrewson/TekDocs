# 0.8.46 invoice revision review correction

Issued invoices remain immutable. The client invoice screen now offers one **Revise invoice** action that creates a linked replacement draft containing every original line. Operators can add a missed item or edit copied details while reviewing the complete revised invoice instead of accidentally creating a delta-only supplement. The supplemental API remains available for integrations that explicitly require a separate additional invoice.

The issue confirmation now lists every line with quantity, unit, unit price, and total alongside the sender, bill-to identity, dates, and invoice total. If issuance is rejected, the page retains the draft and displays the server's specific validation reason. Follow-up drafts preserve saved source identities while filling required legacy gaps from current client and MSP billing defaults; issue-time validation remains authoritative.

The source invoice and its retained artifact remain unchanged. A revision does not automatically void or credit the source receivable. Editable supplemental drafts created by the earlier interface are upgraded in place to complete revisions: source lines are restored first and previously added lines remain afterward. Already-issued supplemental invoices remain immutable.
