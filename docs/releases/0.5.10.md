# TekDocs 0.5.10 simple network records

Date: 2026-08-11

Status: **applicable local slice complete.** No push, tag, published image, deployment, hosted workflow, or external security review was performed.

## Delivered boundary

- Networks is now one restrained list and one form. A record contains its location, name, description, VLAN, CIDR, calculated gateway, assignable range, DNS resolvers, and notes.
- Full usable ranges and gateways are derived from canonical CIDR values. Operators can instead enter one bounded assignable range; they never need to create every host address.
- MAC addresses now appear and are edited on hardware Asset details under asset permissions.
- Racks and network appliances are treated as physical Assets. Their earlier duplicate authoring surfaces have been removed from ordinary Networks navigation.
- The manual NetBox tab is gone. NetBox will return only as a configured integration and reconciliation provider.

## Compatibility and limitations

Existing granular network tables, stable Entity IDs, relationships, exports, and APIs are retained. Migration `0074` extends existing prefix rows and preserves legacy VLAN numbers; migration `0075` extends PostgreSQL scope/range guards. No legacy row is deleted or guessed into a new Asset. Compatibility removal is not scheduled.

DNS fields in this slice are resolver addresses on a Network, not an authoritative DNS-zone manager. Racks can be modeled immediately as hardware catalog products/assets; richer rack placement, if later justified, must augment Assets. NetBox connection configuration remains assigned to the integration framework.

## Evidence

- Focused PostgreSQL backend suites cover simple network creation/range/isolation and hardware-asset MAC behavior.
- Frontend component and API suites cover the simple surface, calculated-field boundary, conditional manual range, search/error behavior, removed NetBox-like navigation, and Asset MAC editing.
- Type checking, migration drift, Django checks, production backend/frontend image builds, and the production-shaped migration service pass.
