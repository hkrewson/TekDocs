# TekDocs 0.5.0 network inventory certification

Date: 2026-08-11

Status: **applicable local certification complete.** No push, tag, image publication, attestation, deployment, live NetBox connection, or external security review was performed.

## Certified boundary

TekDocs `0.5.0` certifies lightweight, exact-Workspace network documentation:

- hardware-asset-backed device roles and rack/site/location placement;
- VLANs, canonical subnets, direct asset IP/MAC assignments, and retained legacy Interface/VRF data;
- wireless posture and permission-aware DNS inventory without secret custody or live control;
- providers, circuits, handoffs, contract lifecycle projections, and protected financial separation;
- relationship-derived topology, fixed-schema search/export, and provider-neutral NetBox identities with non-mutating reconciliation preview.

The MSP Workspace contains only MSP-owned data. Client Workspaces contain only that client's data. There is no cross-client network dashboard, live discovery, connector credential, automatic synchronization, write-back, SNMP monitoring, DNS service, or certificate validation in this release.

## Control disposition

- `TD-RISK-031` through `TD-RISK-038`: **mitigated with recurring owner.** Central permissions, exact Workspace ownership, forced RLS, PostgreSQL edge/conflict guards, bounded interfaces, field-level asset/contract controls, concurrency tests, and recovery evidence remain mandatory.
- Interface/VRF compatibility: **retained and upgrade-safe.** It is hidden from ordinary workflows and not scheduled for destructive removal.
- NetBox seam: **identity and preview only.** Provider runtime trust remains assigned to the integration milestones.
- External release assurance: **unverified by design.** Hosted CI, signed release artifacts, attestations, deployment, and an external assessment were not authorized by this local slice.
