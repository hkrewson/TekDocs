# TekDocs 0.4.7 NetBox identity and reconciliation evidence

Date: 2026-08-11

Status: **implementation and applicable local evidence complete.** No push, tag, image publication, deployment, live NetBox access, or other external change was performed.

## Delivered scope

- Stable exact-Workspace NetBox content-type/numeric-ID references for racks, hardware Assets as devices, MAC addresses, VLANs, prefixes, and IP addresses.
- Explicit exclusion of new Interface and VRF mappings, consistent with the revised lightweight TekDocs boundary and the `0.4.8` simplification milestone.
- Central network permissions, MFA-backed mutation, explicit Workspace ownership, scoped managers, forced RLS, database relationship/type guards, uniqueness, soft unlinking, and value-minimized audit events.
- A duplicate-rejecting, 500-observation deterministic preview reporting current, changed, unmatched, and missing-remote state without persistence or mutation.
- An accessible NetBox identity tab with exact-workspace loading, empty, error, denial, search, link, and unlink-confirmation behavior.

## Deliberate exclusions

- No NetBox base URL, token, connection test, outbound request, job, cursor, webhook, payload mirror, automatic match, import/apply, delete, or bidirectional write-back.
- No claim that a manually entered remote ID exists or that an observation fingerprint is authentic.
- Existing Interface/VRF-era data is not dropped in this slice. `0.4.8` owns a data-preserving simplification rather than an ad hoc destructive migration.
