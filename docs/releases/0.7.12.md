# TekDocs 0.7.12

`0.7.12` adds safe asynchronous TLS certificate monitoring to the existing Domains surface.

## Delivered

- Exact-Workspace, Entity-backed certificate endpoints for domain apexes and managed hostnames.
- Fixed direct-TLS support for HTTPS 443, SMTPS 465, IMAPS 993, and POP3S 995.
- Public-address validation, reviewed-address pinning, authored-hostname SNI, TLS 1.2+, and separate hostname/public-CA trust results.
- Immutable scan history with reduced leaf/chain digests, bounded identity/validity/SAN metadata, and negotiated TLS evidence; raw certificates are discarded.
- Hourly scheduling, leased workers, manual queueing, and retained expiration, change, validation, and collection-failure alerts.
- Endpoint creation, status, alerts, manual checks, and history within each domain's monitoring details.
- Central permissions, non-aggregating MSP/client APIs, PostgreSQL identity/retention guards, forced RLS, permission/IDOR inventory, generated API contract, and hostile-resolution tests.

## Boundary

TekDocs does not scan arbitrary hosts or ports, perform STARTTLS, reach private destinations, retain certificate bodies, or send these alerts through inbox/SMTP. A host or database administrator remains trusted. IDN/wildcard/SAN expansion, scale/accessibility/isolation stabilization, upgrade/restore evidence, and composed monitoring certification remain assigned to `0.7.13` and `0.8.0`.
