# TekDocs 0.8.5 public-beta performance stabilization

Date: 2026-08-13

Status: **local slice complete.** This is not a public release, deployment, tag, push, production sizing promise, or hosted-service capacity claim.

## Delivered boundary

- The blocking PostgreSQL capacity fixture now reaches 100 clients, 100,000 addressable Entities, 250,000 immutable block revisions, and 25,000 assets.
- Authorized first, middle, and last asset pages, deep revision history, and scoped entity search retain fixed whole-request query ceilings and the established 500 ms local p95 tripwire.
- An eight-request authorized burst exercises connection and policy composition with a separate two-second ceiling; no cross-Workspace cache or MSP aggregation path was added.
- Additional application surfaces are route-lazy. The base-shell budget tightens from 500 KiB to 400 KiB, with explicit shell/editor stylesheet limits; the optional editor remains separately loaded.
- WYSIWYG CodeMirror execution is disabled while canonical fenced Markdown and sanitized server rendering remain supported.
- A production-build Chromium rehearsal measures constrained desktop and mobile profiles under CPU/network throttling, verifies the editor is absent from the initial route, and retains a machine-readable metrics attachment.
